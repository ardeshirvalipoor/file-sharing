Linkify

Privacy Policy

Linkify is designed to keep file transfers private. Uploaded file data is stored in private object storage and is not made public.

The app creates signed share links with a short expiration time. Those links are the main way anyone can access a finished file, and they are invalidated as soon as they expire.

If you enable password protection, the app stores only a hash of the password, not the plain text password itself. This helps protect the file without retaining the secret in plain view.

We do not keep a database of the file contents. We keep only the metadata needed to manage the upload and the signed link lifecycle.

Because file-sharing services handle user content, you are responsible for the information you upload and share. Please do not upload personal data or sensitive documents unless you intend to share them via the selected protected link.
