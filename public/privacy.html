Linkify

Privacy Policy

Linkify is designed to keep file transfers private. Uploaded file data is stored in private object storage and is not made public.

The app creates signed share links with a short expiration time. Those links are the main way anyone can access a finished file, and they are invalidated as soon as they expire.

Information we retain

If you enable password protection, the app stores a hash of the password in the file's database row, not the plain text password. This hash is used to check passwords when someone opens a protected link.

We do not store file contents in the database. We do keep file metadata there, including the file identifier, name, content type, size, upload status, timestamps, expiration time, password hash when set, and download count. The file itself is deleted from storage after its link expires.

Each download is logged with the file identifier, time, a keyed hash of the visitor's IP address, and the browser's user-agent string. These download logs and file metadata remain in the database unless they are manually removed.

Because file-sharing services handle user content, you are responsible for the information you upload and share. Please do not upload personal data or sensitive documents unless you intend to share them via the selected protected link.
